# 🏪 Gestão de Lojas (em C)

> 🚧 **Projeto em desenvolvimento.** Este repositório está em construção e vai evoluindo aos poucos. Algumas funcionalidades abaixo ainda são planejadas.

Sistema para auxiliar na gestão de lojas, desenvolvido em **linguagem C**. O objetivo é praticar estrutura de dados, manipulação de arquivos e organização de código em um problema do mundo real.

## Objetivo

Criar uma aplicação que ajude no controle básico de uma loja, como produtos, estoque e vendas, rodando no terminal.

## Funcionalidades

**Planejadas**
- [ ] Cadastro, edição e remoção de produtos
- [ ] Controle de estoque
- [ ] Registro de vendas
- [ ] Armazenamento dos dados em arquivo
- [ ] Relatórios simples (por exemplo, produtos com estoque baixo)

**Concluídas**
- Nenhuma ainda. Esta lista será atualizada conforme o projeto avançar.

## Tecnologias

- Linguagem C
- Compilador: GCC (ou o de sua preferência)

## Como compilar e executar

```bash
gcc -o gestao_lojas main.c
./gestao_lojas
```

> Ajuste o comando de acordo com os arquivos do projeto, quando ele crescer.
